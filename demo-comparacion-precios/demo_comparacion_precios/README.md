# Demo: Datos web / comparación de precios

Esta demo muestra cómo un ecommerce o comercio puede dejar de revisar precios página por página.

## Entrada

`input/productos_a_revisar.csv`

Columnas:

- Producto
- URL
- Sitio

En esta demo las URLs apuntan a páginas HTML locales simuladas dentro de `input/mock_web/`.

## Salida

`output/comparacion_precios.xlsx`

Columnas principales:

- Producto
- Sitio
- Precio actual
- Fecha revisión
- Estado
- Observaciones
- Archivo origen

## Mensaje comercial

Antes: revisar productos o precios página por página.

Después: una planilla con datos públicos ordenados para comparar y revisar más rápido.

Ideal para: ecommerce, comercios, distribuidores y análisis de competencia.
