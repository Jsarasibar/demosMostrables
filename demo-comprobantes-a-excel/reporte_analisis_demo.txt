ANALISIS DETALLADO - DEMO COMPROBANTES A EXCEL

1) Funcionalidad actual
- Objetivo: extraer datos clave desde PDFs de comprobantes y estructurarlos para analisis administrativo/contable.
- Flujo actual:
  1. Recorre input/*.pdf
  2. Extrae texto con PyMuPDF
  3. Busca patrones con regex (fecha, proveedor, CUIT, numero, neto, IVA, total)
  4. Normaliza importes
  5. Imprime registros por consola
- Valor que ya demuestra bien:
  - Reduce carga manual.
  - Estandariza datos que llegan desordenados.
  - Conserva "archivo origen" para trazabilidad.

2) Que hay que cambiar si o si (obligatorio)
- Inconsistencia critica README vs codigo:
  - README dice que genera output/reporte_comprobantes.xlsx.
  - Script actual NO genera Excel, solo imprime diccionarios.
  - Esto debe corregirse si o si para una demo confiable.
- Persistencia de salida:
  - Guardar siempre resultado en archivo (CSV o XLSX), no depender de consola.
- Manejo de faltantes y formato:
  - Si no encuentra un campo, hoy deja vacio/0 sin contexto.
  - Agregar columna "estado_extraccion" y "observaciones" por comprobante.

3) Mejoras recomendadas (simples y de alto impacto)
- Generar dos salidas:
  - reporte_comprobantes.xlsx (para mostrar)
  - output/extraccion_preview.txt o CSV (auditoria tecnica)
- Agregar validaciones contables basicas:
  - Verificar que Neto + IVA ~= Total (con tolerancia)
  - Marcar posibles inconsistencias.
- Agregar resumen final:
  - Cantidad de PDFs procesados
  - Cuantos con extraccion completa
  - Cuantos con alertas

4) Riesgos de demo y mitigacion
- Riesgo: variabilidad de formatos PDF.
  - Mensaje correcto: "Esta demo usa plantillas simuladas; en proyecto real ajustamos patrones por proveedor/tipo de comprobante".
- Riesgo: PDFs escaneados como imagen.
  - Aclarar que ese caso requiere OCR (fuera de alcance de esta demo base).

5) Guion sugerido para demostrar (6-8 min)
- Antes:
  - "Llegan 50 comprobantes y se cargan a mano".
- Automatizacion:
  - Mostrar carpeta input con varios PDFs y ejecutar script.
- Resultado:
  - Abrir Excel final y mostrar columnas estandar.
  - Filtrar por proveedor o fecha.
- Cierre:
  - "Se pasa de carga manual repetitiva a revision de excepciones".

6) Alcance recomendado (mantener demo liviana)
- Mantener:
  - Regex + PDF de texto
  - Campos principales
  - Trazabilidad por archivo
- Evitar por ahora:
  - OCR avanzado
  - Clasificacion documental con IA
  - Multiples tipos de moneda/impuestos complejos

7) Checklist de "demo lista para vender"
- Script efectivamente crea el Excel prometido.
- Todos los PDFs de input se ven en la salida.
- Existe al menos un caso con alerta controlada.
- README, script y resultado coinciden.
- Mensaje comercial se entiende en menos de 1 minuto.

Conclusion
La demo tiene una propuesta muy fuerte y concreta, pero hoy hay una brecha funcional importante: la salida prometida no se genera desde el script actual. Corrigiendo eso y agregando estado de extraccion, queda excelente para mostrar automatizacion real con bajo riesgo.
